# NODEJS56 - CAPSTONE ORM PINTEREST

Backend API mô phỏng một số chức năng cơ bản của Pinterest.

## Công nghệ sử dụng

- Node.js
- ExpressJS
- Prisma ORM
- MySQL
- JWT
- bcrypt
- Docker
- Swagger

## Chức năng chính

- Đăng ký tài khoản
- Đăng nhập
- Lấy danh sách ảnh
- Tìm kiếm ảnh theo tên
- Xem chi tiết ảnh
- Xem và thêm bình luận
- Lưu / bỏ lưu ảnh
- Xem thông tin người dùng
- Xem ảnh đã lưu
- Xem ảnh đã tạo
- Xóa ảnh do chính người dùng tạo
